# DTTL 连续长流：随机数据中插入长交替序列

```powershell
./scripts/run_dttl_supervisor_sim.ps1 -Tests tb_DTTL_MixedStream -OutputDir E:/k7_clean/temp/dttl_mixed_stream_sim
```

本测试是单条连续流，不在不同数据段之间复位，也不在段间注入定时相移。
使用当前 DTTL RTL、真实 Divider Generator 功能网表和 MULT_MACRO。
MODE3，同频、无噪声、幅度 ±500，每拍输入一个有效采样。
初始相差半个符号，保留原有 supervisor 的半周期初相重启方案。

## 数据组成

总计 4096 个发送符号，按工程名义 8 ksym/s 对应约 0.512 秒数据。
前 512 个符号为 PRBS 捕获区，之后在 PRBS 中随机插入 4 段连续 `0101…`。
插入间隔随机取 128～255 个符号，每段交替数据随机取 256～511 个符号。
位置随机数种子为 0x6d2b79f5，PRBS 数据种子为 0xace1，可重复同一组数据。

本次生成的区间（发送符号序号从 0 开始，结束位置不包含在区间内）：

| 段 | 起始位置 | 长度 | 结束位置 |
| --- | ---: | ---: | ---: |
| 交替段 1 | 671 | 281 | 952 |
| 交替段 2 | 1120 | 413 | 1533 |
| 交替段 3 | 1737 | 487 | 2224 |
| 交替段 4 | 2364 | 279 | 2643 |

其余位置为 PRBS。每段交替数据从 0 开始。最后一段结束后还有 1453 个 PRBS 符号。
发送端在 4096 个数据符号后额外运行 4 个 PRBS 符号，供接收端输出最后几笔积分；
这 4 个排空符号不计入 4096 个数据符号和验收数目。

## 验收

前 512 个发送符号允许捕获和重启；从发送符号 512 到 4095 的 **3584 个符号逐个检查**：

- 边界偏差始终小于 0.05T，逐符号判决错误为 0。
- 解调出的发送符号序号连续，无漏符号、重复符号或错位。
- 4 个交替段均完整覆盖，逐段统计相位偏差、错误数。
- 捕获后不能再次触发 supervisor 重启。
- 初始捕获应只触发一次重启，两拍均保持 0x80000001，并正确屏蔽复位后的首笔积分。

数据段之间不清空累计统计，也不重新开始验收窗口。`DTTL_MIXED_STREAM_TEST_PASS`
只有在上述条件全部满足后输出。

## 输出

输出目录 `temp/dttl_mixed_stream_sim/`：

- `mixed_stream_bits.csv`：4096 个实际发送比特及所属交替段编号；0 表示 PRBS。
- `mixed_stream_symbols.csv`：全部接收积分、相位、频率控制字、发送参考与判决结果。
- `mixed_stream_events.csv`：每个数据段切换和 supervisor 重启的时刻。
- `mixed_stream.wdb` / `mixed_stream.wcfg`：连续 XSim 波形和显示配置。
- `tb_DTTL_MixedStream.log`：数据段配置、运行进度、逐段统计与总验收结果。

定时距离由模相位差计算，`min(phase_error/2^32, 1-phase_error/2^32)`。
发送参考从独立生成的比特数组中按积分区间的名义中点查找，
同时检查发送索引连续性，避免仅以“输出了一个看起来正确的比特”判断通过。

该测试验证理想同频条件下的连续保持和数据切换行为，不包含噪声、采样缺口、频偏、
MODE1/2 或额外强制误锁注入；后续交替段开始时不会人为制造新的半周期偏差。
